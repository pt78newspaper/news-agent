# NewsAgent PT78

Personal news aggregator. Collects news from Russian and international media,
groups by topic, shows different regional perspectives.

**Schedule:** Daily via GitHub Actions (cron 03:30 UTC). Note: GitHub's free
scheduler typically starts the run a few hours later — the page just refreshes
once a day, whenever the runner gets to it.
**Page:** https://pt78newspaper.github.io/news-agent/
